Remarks

The ActionLog mapping is provider-aware: when the database provider name contains Npgsql, snake_case table/column/index names and PostgreSQL column types are used; otherwise PascalCase names and provider-default column types are used (e.g. for SQLite in tests).

SaveChangesWithAuditAsync(Guid?, Formatting?)

Saves all changes made in this context to the database and writes an ActionLog record for every added, modified or deleted entity.

public Task<int> SaveChangesWithAuditAsync(Guid? actionBy = null, FormattingHelper.Formatting? formatting = null)

Parameters

actionBy Guid?

The identifier of the user making the change, stored in CreatedBy.

formatting FormattingHelper.Formatting?

The naming convention applied to ReferenceTable and ColumnName. When it is KYS.Library.Helpers.FormattingHelper.Formatting.SnakeCase, the keys of RecordValue are converted to snake_case as well. null keeps the original names.

Returns

Task<int>

The number of state entries written to the database by the main save, including the audit records that could be created before saving.

Remarks

  1. Changes are detected and an AuditEntry is built for each tracked entity (excluding ActionLog entities and detached or unchanged entries).
  2. Audit records whose values are already known are added, then the changes are saved.
  3. Audit records for entities with database-generated values (e.g. identity keys) are completed with the generated values and saved with a second SaveChangesAsync(CancellationToken) call.

The two saves are not wrapped in a transaction by this method. Use an IUnitOfWork (or an explicit transaction) if both must succeed or fail together.

Exceptions

InvalidOperationException

An audit entry could not be converted to an ActionLog, for example because a name could not be formatted.
