Converts this audit entry to an ActionLog.

public Result<ActionLog> ToActionLog(FormattingHelper.Formatting? formatting = null)

Parameters

formatting FormattingHelper.Formatting?

The naming convention applied to ReferenceTable and ColumnName. When it is KYS.Library.Helpers.FormattingHelper.Formatting.SnakeCase, the keys of RecordValue are converted to snake_case as well. null keeps the original names.

Returns

Result<ActionLog>

A successful CSharpFunctionalExtensions.Result<T> containing the ActionLog, or a failed result with an error message when the table or column name could not be formatted.

Remarks

  • Insert: RecordValue holds the key and new values as JSON.
  • Update: ColumnOldValue and ColumnNewValue hold the values of ColumnName.
  • Delete: RecordValue holds the key and original values as JSON.
ReferenceId is taken from the first entry of KeyValues.

Exceptions

InvalidOperationException

Action is Update and ColumnName has no matching entry in OldValues or NewValues.
